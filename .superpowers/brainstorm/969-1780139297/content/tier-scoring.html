Tier Scoring Formula

How should A/B/C/D tiers be computed from screener performance history?

A

Percentile Rank

Rank all screeners by composite score. Always produce all 4 tiers regardless of absolute quality.

composite = 0.4×win_rate_20d + 0.3×alpha_vs_nifty + 0.2×sharpe + 0.1×(1−drawdown)

Tier A = top 15% by composite
Tier B = 16–40%
Tier C = 41–70%
Tier D = bottom 30%
✓ Always has Tier A screeners
✗ Tier A may still be mediocre if all screeners are bad
B

Bayesian Score (Recommended)

Shrink each screener's stats toward the global mean based on sample size. Small-sample screeners get pulled to average; well-tested screeners keep their true score.

// Bayesian shrinkage: n signals, global_mean win rate
shrunk_wr = (n × win_rate + k × global_mean) / (n + k)
// k=20 means need 20+ signals to trust own win rate

composite = 0.4×shrunk_wr + 0.3×alpha + 0.2×sharpe + 0.1×consistency

Tier A = composite ≥ 0.70
Tier B = 0.55–0.69
Tier C = 0.40–0.54
Tier D = <0.40 or <10 signals
✓ New screeners won't falsely rank high on 2 wins
✓ Tier A means genuinely good, not just top-of-bad
✗ Slightly more complex to compute
C

Simple Absolute Thresholds

Win rate + alpha alone, no weighting magic. Easy to explain: "Tier A = beats Nifty 65%+ of the time on 20-day holds."

Tier A = win_rate_20d ≥ 0.65 AND alpha ≥ 3%
Tier B = win_rate_20d ≥ 0.55 OR alpha ≥ 1.5%
Tier C = win_rate_20d ≥ 0.45
Tier D = win_rate_20d < 0.45 or insufficient data

// Minimum 15 resolved signals to qualify for A/B
✓ Transparent, explainable to users
✗ No Sharpe/drawdown consideration
✗ 3-win screener with 100% rate gets Tier A
Note on data availability: Current signal_outcomes has 4,957 resolved rows (1,651 WIN / 1,183 LOSS) across all screeners. Many screeners will have <10 resolved outcomes — Bayesian shrinkage handles this gracefully; absolute thresholds would leave most screeners as Tier D or Unranked.
