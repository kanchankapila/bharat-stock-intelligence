How should ambiguous screener names be classified?

A

Keyword rules only

Extend the existing categorizeScreener() with ~120 keyword rules. Fast, deterministic, no external calls. Uncategorisable ones stay "other".

B

Keywords first, Ollama fallback

Run keyword rules first. For "other" screeners, call local Ollama to classify from name + description. One-time batch, result cached in DB.

C

Keywords first, Gemini fallback

Same but use Gemini API for the 633 "other" screeners. Faster/more accurate than Ollama but costs API credits. One-time batch.
