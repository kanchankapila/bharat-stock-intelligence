Critical Data Gap — Screener History

Screener stock tables store only the current snapshot, not when a stock appeared. Two approaches to fix this.

⚠️ The Problem
trendlyne_screener_stocks / moneycontrol_screener_stocks / etnow_screener_stocks — each has (screener_id, symbol) with no date column.
Every sync overwrites the list. We don't know when a stock first appeared in a screener — so we can't measure "what happened 20 days after it appeared."
A

Add screener_appearances table (forward-looking)

Every sync run, diff the current screener stocks against the previous snapshot. Record new appearances with a date. Performance is computed from these dated appearances against OHLCV.

screener_appearances:
  screener_id, symbol, appeared_date, exited_date

performance = join with stock_ohlcv
  WHERE date = appeared_date + N days
  → return_pct, win/loss per horizon
✓ Clean, accurate, grows over time
✓ Enables combination analytics (Phase B)
✗ No historical data — tiers meaningful only after 60-90 days
B

Use recommendation_log as proxy (immediate)

22,175 recommendations already exist with outcomes. Extract screener signals from signals_json + screener_score. Compute per-screener win rates from resolved outcomes immediately.

recommendation_log
  → signals_json (has active screeners)
  → outcome (WIN/LOSS/NEUTRAL)
  → actual_return_pct

GROUP BY screener_id → win_rate, avg_return
✓ Immediate results — 22K rows usable today
✗ Only covers screeners that triggered recommendations
✗ signals_json may not itemise per-screener contribution
C

Both — proxy now, appearances going forward (Recommended)

Bootstrap initial tiers from recommendation_log today. Simultaneously start recording screener_appearances on every sync. Tiers improve automatically as appearance history accumulates.

Day 0: tiers from recommendation_log proxy
Day 30+: appearances data starts filling in
Day 90+: appearance-based tiers dominate
Continuous: Bayesian blend of both sources
✓ Useful immediately
✓ Accurate long-term
✓ Enables Phase B combination engine
