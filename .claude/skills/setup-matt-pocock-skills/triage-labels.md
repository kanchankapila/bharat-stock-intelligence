# Summary of Triage Labels

This documentation outlines a mapping system for issue triage across a repository's tracker. The framework establishes five standardized roles:

1. **needs-triage** — A maintainer must evaluate the issue
2. **needs-info** — The issue reporter should provide additional details
3. **ready-for-agent** — Fully specified, ready for an AFK agent
4. **ready-for-human** — Implementation requires human involvement
5. **wontfix** — The issue will not receive action

The key guidance emphasizes consistency: when a skill references a triage role, apply the corresponding label string from the table. The documentation also notes that teams should customize the right-hand column to align with their own terminology, suggesting this is a flexible template rather than a rigid standard.
